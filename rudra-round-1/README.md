# Rudra Round 1 — C Debugging

## Problem

You are given a small C project for a robot telemetry calculator.

Fix the code so that the program produces the expected output.

### Expected output

Numbers: 10 5 8
Sum: 23
Product: 400
Even numbers: 10 8

### Rules

- Do not rewrite the project from scratch.
- Find and fix the existing bugs.
- You may edit any source/header file.
- Make sure the program compiles and runs correctly.

### Build

From the rudra-round-1 directory:

gcc main.c calculator.c utils.c -o rudra

Then run:
./rudra

On Windows PowerShell:
.\rudra.exe

Good luck.
